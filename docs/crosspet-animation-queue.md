# CrossPet 逐圖補幀清單

本表保留既有 GIF 批次的狀態與合併安排。後續以新圖生成新批次（例如 deepseek）請依 [共用製作流程](crosspet-gif-production-guide.md) 另建工作單；若要求每圖一支，不能沿用本表的合併或靜態略過規則。Claude 新批 60/60 的實際結果見 [工作單](crosspet-image26-gif-worklist.md)。

依編號執行。每張動作圖優先獨立補畫起勢、主要動作與回位。只有姿勢可直接接成同一動作才合併，並補畫中間幀。頭像與立繪卡保留靜態。

完成一項後更新狀態與 GIF 路徑，再往下一號。先前的姿勢切換預覽不計為已補幀。
